# Code of conduct

The OpenRater community adopts the **Contributor Covenant v2.1**
verbatim as our code of conduct:

- Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Translations: https://www.contributor-covenant.org/translations/

Adopted: 2026-07-17.

## In one sentence

We're building an OSS substrate for property + casualty insurance
rating. Everyone is welcome to contribute — actuaries, engineers,
designers, regulators, students. We expect contributors to treat
each other with respect, focus discussions on the work, and assume
good faith.

## Reporting

If you experience or witness behavior that violates the Contributor
Covenant, please report it via one of the following:

- **GitHub** — contact a maintainer directly (handles in
  [`MAINTAINERS.md`](./MAINTAINERS.md)), or email the address on
  their GitHub profile with `[openrater conduct]` in the subject.
- If the report concerns a maintainer, say so — we will arrange an
  uninvolved reviewer.

Reports are kept confidential. We follow the Contributor Covenant's
enforcement ladder (Correction → Warning → Temporary Ban → Permanent
Ban) per §3 of the linked text.

## Scope

The code of conduct applies to:

- All project spaces (GitHub repo, issues, PRs, discussions).
- Any official communications channel (mailing list, Slack, etc. —
  none today; documented here for when they exist).
- When a contributor represents OpenRater publicly (conference
  talks, blog posts citing the project, etc.).
